# परिवर्तन सूची

Version 0.7.1 – 2026-05-13

नई सुविधाएँ और सुधार
• आधिकारिक वेबसाइट sonarpad.com बनाई गई है, जो नवीनतम समाचारों का अनुसरण करने, कार्यक्रम का नवीनतम संस्करण डाउनलोड करने, आगंतुकों की टिप्पणियाँ पढ़ने और भविष्य में Sonarpad के सभी पॉडकास्ट सुनने के लिए एक नया संदर्भ बिंदु है। सहायता मेनू में “sonarpad.com पर जाएँ” विकल्प भी जोड़ा गया है, ताकि आधिकारिक वेबसाइट को जल्दी खोला जा सके।
• वह समस्या ठीक की गई जिसमें उच्चारण चिह्नों या विशेष वर्णों वाले फ़ाइलों पर वॉइस ट्रांसक्रिप्शन शुरू करने पर त्रुटि आती थी।
• अब से, दृश्य मेनू में Automatic word wrap और Show video during playback जैसे विकल्प हमेशा सही स्थिति दिखाएंगे, यानी चालू या बंद।
• YouTube खोज को बेहतर किया गया है, जिससे Esc दबाकर पिछली पेज या स्क्रीन पर वापस जाया जा सकता है।
• यह जांचने के लिए प्रारंभिक नियंत्रण जोड़ा गया है कि कोई वीडियो चलाया जा सकता है या नहीं। प्लेबैक भी बेहतर किया गया है: Sonarpad अब उन वीडियो या playlists को भी चला सकता है जिन्हें mix के रूप में चिह्नित किया गया है और जो पहले नहीं चलते थे।
• स्वचालित बुकमार्क प्रबंधन बेहतर किया गया है। पहले, यदि Automatic bookmarks विकल्प चालू था और फिर बंद किया गया, तो वे बुकमार्क बने रहते थे; अब प्रोग्राम उन्हें सही तरीके से अनदेखा करता है जब तक विकल्प फिर से चालू न हो। इसके अलावा, जब मीडिया फ़ाइल के अंत तक पहुंचा जाता है, तो बुकमार्क अपने-आप हट जाता है।
• सक्रिय संवादों के साथ टैग प्रबंधन बेहतर किया गया है। Sonarpad अब दोनों सुविधाओं को सही तरीके से संभालता है, जिससे dialog विकल्प चालू होने पर भी टैग डाले जा सकते हैं।
• आवाज़ सेटिंग्स को बेहतर किया गया है, हर इंजन को स्पष्ट रूप से अलग करके, ताकि समायोजन अधिक सटीक हो। Voice profiles अब हर अलग इंजन के लिए सेटिंग्स सही तरीके से रखते हैं: Edge, Sapi5 और Sapi4।
• Pause डालने के लिए एक टैग जोड़ा गया है, सीधे options से या editor से Tab दबाकर voices panel से। विकल्प हैं: 250 ms, 500 ms, 1 second, 2 seconds या custom duration।
• YouTube वीडियो चलाते समय और transcription शुरू करते समय व्यवहार ठीक किया गया है। अब Alt+Tab से वापस आने पर focus सही तरीके से चल रही transcription के Cancel बटन पर होगा।
• अब transcription प्रक्रिया पूरी होने पर अपने-आप सेव हो जाती है।
• Wikipedia से import बेहतर किया गया है। अब केवल एक section पढ़ने का विकल्प चुना जा सकता है और फिर article से Esc दबाकर search पर वापस जाया जा सकता है, या पूरा article import किया जा सकता है। Wikipedia की भाषा भी चुनी जा सकती है।
• दुनिया भर की radio stations के लिए एक section जोड़ा गया है, जहां country, language और genre के आधार पर radio खोजा जा सकता है। Local radio stations को Sonarpad database में भी जोड़ा जा सकता है, ताकि अन्य users भी उन्हें सुन सकें। Radio को favorites में भी जोड़ा जा सकता है।
• Routes के लिए एक section जोड़ा गया है, जहां travel mode चुनकर रास्ते calculate किए जा सकते हैं: walking, cycling, driving या wheelchair। Shortest या fastest route चुना जा सकता है और crossed municipalities दिखाने का विकल्प भी है। Route import होने के बाद visual map को File menu, Save image से सेव किया जा सकता है।
• File menu में Print आइटम जोड़ा गया है। Sonarpad TXT files को अपने सिस्टम से print करेगा और DOCX, PDF जैसी अन्य files के लिए associated program का उपयोग करेगा, ताकि original layout अधिकतम सुरक्षित रहे।
• Sonarpad में हर document के लिए translation service जोड़ी गई है, जो editor context menu से उपलब्ध है। User बिना कोई API key डाले free DeepL और Google Translate services का उपयोग कर सकता है; Gemini API key डालने पर Gemini से translate कर सकता है।
• Translation menu में user target language चुन सकता है। Menu अपने-आप reorder होता है: यदि user पहले English, फिर French और फिर Italian चुनता है, तो ये तीन options language menu के ऊपर दिखेंगे।
• यदि user अपनी Gemini API key डालता है, तो वह Summarize text सुविधा भी उपयोग कर सकता है, जो context menu में उपलब्ध है और किसी भी article का summary बना सकती है।
• Playback menu में, जो media file चलाते समय दिखाई देता है, current media को split करने का menu जोड़ा गया है। यह MP3, MP4 और अन्य formats के साथ काम करता है, number of parts के आधार पर या हर part की duration के आधार पर split कर सकता है।

Version 0.7.0 – 2026-04-25

नया क्या है
• स्ट्रीमिंग प्लेबैक के लिए mpv प्लेयर का समर्थन जोड़ा गया है। YouTube और समर्थित साइटों के वीडियो अब तुरंत चलाए जाते हैं; यदि उपयोगकर्ता उन्हें सहेजना चाहता है, तो वे पहले की तरह डाउनलोड किए जाते हैं। स्ट्रीमिंग सामग्री का ट्रांसक्रिप्शन शुरू करने पर, उसे पहले डाउनलोड किया जाता है और फिर ट्रांसक्राइब किया जाता है। mpv प्लेयर का उपयोग स्थानीय वीडियो खोलने और उपशीर्षक संभालने के लिए भी किया जाता है, जिससे कई फ़ॉर्मैट्स के साथ बेहतर संगतता मिलती है।
• सिस्टम ऑडियो के लिए पॉडकास्ट रिकॉर्डिंग में सुधार किया गया है: अब आप चुन सकते हैं कि पूरा सिस्टम ऑडियो रिकॉर्ड करना है, केवल एक एप्लिकेशन रिकॉर्ड करना है, या एक ही समय में कई एप्लिकेशन रिकॉर्ड करने हैं। यह विकल्प सामान्य रिकॉर्डिंग में एकीकृत है, इसलिए माइक्रोफ़ोन को अब भी अलग से सक्षम या अक्षम किया जा सकता है।
• हिंदी भाषा जोड़ी गई। इंटरफ़ेस का अनुवाद किया गया और RSS, चेंजलॉग तथा Sonarpad गाइड जोड़े गए।
• एडिटर टैब में एक विकल्प जोड़ा गया है, जिससे ऊपर और नीचे तीर कुंजियों का उपयोग करने पर कर्सर हमेशा पंक्ति की शुरुआत में चला जाता है।
• "ऑडियो कन्वर्ट करें" मेनू में ऑडियो को M4B में बदलने का विकल्प जोड़ा गया।

बग सुधार
• `F10` को ठीक किया गया है, ताकि यह टेक्स्ट पढ़ते समय फिर से अगली पसंदीदा वॉइस पर स्विच करे।
• अब यदि पॉडकास्ट रिकॉर्डिंग चल रही हो, तो किसी दूसरे दस्तावेज़ को बंद करने से सक्रिय रिकॉर्डिंग बंद नहीं होती।
• "Play streaming audio..." से खोली गई YouTube टिप्पणियों में, Sonarpad अब शुरुआत में केवल पहली 50 शीर्ष-स्तरीय टिप्पणियाँ लोड करता है, और उन टिप्पणियों के सभी उत्तर हमेशा शामिल करता है। साथ ही, आवश्यकता होने पर सभी टिप्पणियाँ लोड करने के लिए अंत में एक अतिरिक्त आइटम जोड़ा गया है।
• अब बुकमार्क टेक्स्ट दस्तावेज़ों और मीडिया फ़ाइलों दोनों में निर्माण क्रम के बजाय स्थिति क्रम में दिखाए और संभाले जाते हैं। यदि उसी स्थिति पर पहले से कोई बुकमार्क मौजूद है, तो उसे दोबारा नहीं जोड़ा जाता।
• बुकमार्क मेनू में एक विकल्प जोड़ा गया है, जिसे सक्षम करने पर बुकमार्क का स्वचालित प्रबंधन किया जा सकता है। जब कोई स्थानीय या स्ट्रीमिंग फ़ाइल चलाकर बंद की जाती है, तो Sonarpad पहुँची हुई स्थिति के आधार पर अपने आप एक बुकमार्क सेट करता है और फ़ाइल दोबारा खोलने पर उसी स्थान से फिर शुरू करता है। यही बात टेक्स्ट फ़ाइलों पर भी लागू होती है: यदि कोई टेक्स्ट खोला जाता है और कर्सर को स्थानांतरित किया जाता है, तो फ़ाइल बंद करते समय Sonarpad उस स्थिति को याद रखेगा; यदि पढ़ना शुरू किया जाता है, तो अंतिम पढ़ा गया वाक्य सहेजा जाएगा और पढ़ना ठीक वहीं से फिर शुरू होगा।
• दृश्य मेनू में स्थानीय या स्ट्रीमिंग फ़ाइलों के लिए वीडियो रेंडरिंग दिखाने का एक विकल्प जोड़ा गया है। वीडियो सामग्री एक बड़े विंडो में दिखाई जाती है, जहाँ सभी नियंत्रण छिपे रहते हैं, सिवाय इसके कि Alt कुंजी दबाई जाए या माउस को विंडो के ऊपरी भाग की ओर ले जाया जाए। इस तरह कम दृष्टि वाले उपयोगकर्ताओं को सामग्री बड़ी और अधिक उपयोगी रूप में मिलनी चाहिए।

Version 0.6.9 – 2026-04-08

बग सुधार
• Find in Files अनुभव को बेहतर बनाया गया है: Browse Folder खोलने पर फ़ोकस अब सीधे फ़ोल्डर सूची पर जाता है; Enter से परिणाम खोलने पर कीबोर्ड कमांड अब बाधित नहीं होते; Esc दबाने पर पहले चयनित परिणाम पर वापस लौटा जाता है; और Alt+Tab से लौटने पर फ़ोकस या तो खोज फ़ील्ड पर जाता है या, यदि परिणाम खुले हों, तो परिणाम सूची पर जाता है।
• पहले F5 हमेशा शुरुआत से पढ़ना शुरू करता था। अब इसे ठीक कर दिया गया है, और पढ़ना वर्तमान caret स्थिति से शुरू होता है, जबकि `Shift+F5` और `Ctrl+F5` क्रमशः पिछले और अगले वाक्य पर जाने के लिए सुरक्षित रखे गए हैं।
• Go to Line का उपयोग करने के बाद Esc दबाने पर फ़ोकस Sonarpad से बाहर जा सकता था। अब यह सही ढंग से एडिटर पर वापस लौटता है।
• `Word Wrap` विकल्प अब पहले से खुले दस्तावेज़ों पर तुरंत लागू होता है; इसके लिए फ़ाइल दोबारा खोलने की आवश्यकता नहीं है।

Version 0.6.8 – 2026-04-07

नया क्या है
• Play मेनू में एक नया आइटम जोड़ा गया है, जिससे आप Whisper के साथ किसी भी ऑडियो या वीडियो फ़ाइल का ट्रांसक्रिप्शन कर सकते हैं। Options में अब एक नई “AI and Transcription” सेक्शन उपलब्ध है, जहाँ आप मॉडल चुन सकते हैं, NVIDIA graphics cards के लिए वैकल्पिक CUDA समर्थन सक्षम कर सकते हैं, मूल भाषा सुरक्षित रख सकते हैं, और timestamps को सक्षम या अक्षम कर सकते हैं।
• Play मेनू में नई क्रिया `Transcribe current folder` जोड़ी गई है, जो वर्तमान में खुले मीडिया के फ़ोल्डर में मौजूद सभी समर्थित ऑडियो फ़ाइलों को एक संयुक्त दस्तावेज़ में ट्रांसक्राइब करती है। इसमें समर्पित प्रगति, वर्तमान फ़ाइल की स्थिति और रद्द करने का समर्थन शामिल है। इसे `Alt+Shift+C` से भी शुरू किया जा सकता है।
• ऑफ़लाइन वॉइस डिक्टेशन जोड़ा गया है, जो ऑडियो ट्रांसक्रिप्शन वाले ही कार्यप्रवाह का उपयोग करता है। डिफ़ॉल्ट रूप से, डिक्टेशन शुरू करने के लिए `Ctrl+Shift+Space` दबाएँ और रोकने के लिए वही शॉर्टकट फिर से दबाएँ; इस शॉर्टकट को Options में बदला जा सकता है। दूसरी बार से डिक्टेशन तेज़ हो जाता है, क्योंकि इंजन मेमरी में तैयार रहता है। 4 GB से कम RAM वाले PCs पर यह preloading और reuse स्वतः अक्षम हो जाते हैं।
• एक नया Editor विकल्प जोड़ा गया है, जो डिफ़ॉल्ट रूप से अक्षम है और `Esc` दबाने पर एडिटर विंडो बंद कर देता है।
• पॉडकास्ट खोज अब डिफ़ॉल्ट रूप से `iTunes + Spreaker` का उपयोग करती है, और यदि वही पॉडकास्ट दोनों प्लेटफ़ॉर्म पर मिले, तो डुप्लिकेट को फ़िल्टर किया जाता है।
• Apple पॉडकास्ट ब्राउज़िंग और खोज में सुधार किया गया है: पॉडकास्ट खोज, श्रेणी ब्राउज़िंग, और श्रेणी अनुसार शीर्ष पॉडकास्ट अब चयनित पॉडकास्ट निर्देशिका देश का उपयोग करते हैं। Options > RSS / Podcast में आप इसे `Automatic` पर छोड़ सकते हैं ताकि सिस्टम देश का उपयोग हो, या कोई दूसरा देश मैन्युअल रूप से चुन सकते हैं।
• Apple पॉडकास्ट श्रेणियों के लिए परिणाम सीमा बढ़ा दी गई है। पहली बार खोलने पर पहले की तरह केवल शुरुआती 50 परिणाम लोड होते हैं; यदि आप `Load more results` चुनते हैं, तो Sonarpad कुल 200 परिणाम (Apple की सीमा) तक लोड करता है और अनुभव को सहज रखते हुए आगे के पृष्ठों पर नेविगेट करने देता है।

बग सुधार
• "Play streaming audio..." अब Options में पहले से सेट podcast cache limit का पालन करता है, और वही सीमा अब audio descriptions playback पर भी लागू होती है।
• Wikipedia import को ठीक किया गया है, ताकि पृष्ठों में मौजूद quote blocks अब सही ढंग से आयात हों।
• WordPress पृष्ठों के लिए web page parser बेहतर किया गया है, जहाँ list items और कुछ section headings छूट सकते थे।
• "Go to line" अब वर्तमान पंक्ति से फ़ील्ड पहले से भरता है।
• podcasts और RSS के लिए OPML export ठीक किया गया है, ताकि export की गई फ़ाइलें अब iTunes द्वारा स्वीकार की जाएँ।
• RSS feeds और podcasts के सही OPML import/export के लिए localized confirmation messages जोड़ी गई हैं।
• एक बग ठीक किया गया है, जिसमें "Play streaming audio..." में search string टाइप करने और परिणामों से YouTube channel चुनने पर, उस channel के videos खोलने के बजाय program अटका हुआ प्रतीत हो सकता था।
• एक बग ठीक किया गया है, जिसमें open files की सूची Window menu के बजाय Help menu में दिखाई जाती थी।
• एक streaming edge case ठीक किया गया है, जहाँ playback शुरू हो सकती थी, लेकिन “Downloading stream” dialog खुला रहता था यदि downloaded file पहले से target format से मेल खाती थी।
• MP3 streaming conversion behavior ठीक किया गया है: यदि stream पहले से MP3 हो और उपयोगकर्ता स्पष्ट MP3 bitrate चुने (उदाहरण के लिए 128 kbps), तो Sonarpad अब conversion छोड़ने के बजाय चुने गए bitrate पर फिर से encode करता है।
• media transcription documents ठीक किए गए हैं, ताकि अब उन्हें बंद करने पर save करने के लिए पूछा जाए, और सुझाया गया file name अब पाठ की पहली पंक्ति के बजाय transcribed media file name का पुनः उपयोग करे।
• `Alt+Shift+L` shortcut ठीक किया गया है: अब यह playback के दौरान chapter list सही ढंग से खोलता है।
• `Alt+Shift+T` shortcut ठीक किया गया है: अब यह Tools menu खोलने के बजाय “Transcribe current audio” सही ढंग से शुरू करता है।
• Play menu में playback stop handling ठीक की गई है: `.` दबाने पर अब यह Stop की तरह व्यवहार करता है और केवल वर्तमान track को रोकता है, player/episode से बाहर नहीं निकलता।
• Recent Files से खोले गए media के लिए Play menu की save entry ठीक की गई है: जब फ़ाइल local Sonarpad cache से आती है, तो localized save action अब वहाँ भी सही ढंग से दिखाई देती है।
• जब transcription शुरू होती है जबकि audio पहले से चल रही हो, Sonarpad अब transcription शुरू करने से पहले उस audio को स्वतः pause कर देता है।
• एक बग ठीक किया गया है, जिसमें Wikipedia से article import सफल हो सकती थी, लेकिन article text स्क्रीन पर नहीं दिखता था।
• local media files से embedded podcast chapters का समर्थन जोड़ा गया है (उदाहरण के लिए MP3 chapter metadata): जब feed/URL chapters उपलब्ध न हों, तो Sonarpad अब background में downloaded file से chapters लोड करता है, ताकि playback तुरंत शुरू हो और chapter data तैयार होते ही लागू हो जाए।
• downloaded podcast episodes को सामान्य local media files के रूप में खोलने पर chapter loading ठीक की गई है: embedded chapters अब वहाँ भी उपलब्ध हैं, केवल Podcasts window से playback शुरू होने पर ही नहीं।
• SAPI4 और SAPI5 के लिए MP3 audiobook finalization ठीक की गई है: लंबे export के बाद incomplete या fragile files से बचने के लिए final output अब सही ढंग से finalize होती है।
• सभी audiobook creation modes के लिए एक स्पष्ट finalization progress bar जोड़ी गई है: creation phase के बाद Sonarpad अब visible progress के साथ एक समर्पित finalization phase की घोषणा और प्रदर्शन करता है।
• dialogue voice tuning ठीक की गई है: synthesis के दौरान अब speed/pitch/volume settings पहली और दूसरी dialogue voices दोनों पर सही ढंग से लागू होती हैं।
• Japanese `.txt` files के लिए text encoding detection बेहतर की गई है: mojibake के मामलों के लिए सुरक्षित Shift_JIS/CP932 fallback जोड़ा गया है, जबकि मौजूदा UTF/diacritics/Chinese behavior सुरक्षित रखा गया है।
• Internal safety refactor: जहाँ संभव था वहाँ functions को safe implementations में बदला गया है और unsafe code lines को काफ़ी कम किया गया है।

• SAPI 4: error handling और temporary files की automatic cleanup बेहतर की गई है।
• Find dialog: स्पष्टता के लिए "Regex" का नाम बदलकर "Regular expression" किया गया है और search options के लिए missing translations जोड़ी गई हैं।

• podcast download filters को नए audio/video formats शामिल करने के लिए update किया गया है।

• YouTube transcript import को अधिक robust और resilient बनाया गया है।

• hang detection system बेहतर किया गया है, ताकि modal dialogs (error messages, "text not found") खुले होने पर false positives से बचा जा सके।

डेवलपर सुधार
• errors अब silently drop नहीं होते: सभी let _ = patterns हटा दिए गए हैं, और errors को अब स्पष्ट रूप से handle किया जाता है (जहाँ उपयुक्त हो वहाँ propagate, log, या fallback के साथ handle किया जाता है)।
• यदि warnings हों तो project अब compile नहीं होता: cargo check और cargo clippy दोनों को clean pass करना आवश्यक है, lints को कड़ा किया गया है और जहाँ संभव हो allow हटाया गया है।
• strlen / wcslen-style helpers जैसी custom implementations हटा दी गई हैं। string और UTF-16 buffer lengths अब memory scan करने के बजाय Rust-owned data से प्राप्त की जाती हैं।
• DLL handling को साफ़ और libloading के आसपास एकीकृत किया गया है, जिससे custom loader logic और PE parsing से बचा जा सके।
• hand-rolled byte parsing helpers हटा दिए गए हैं; अब सभी byte parsing checked slices पर standard from_le_bytes / from_be_bytes का उपयोग करती है।
• ये परिवर्तन अनावश्यक unsafe usage को कम करते हैं, संभावित undefined behavior को समाप्त करते हैं, और codebase को अधिक idiomatic, robust और maintainable बनाते हैं।
