# Changelog

Версия 0.6.8 – 2026-03-31
Новое
• В меню Воспроизведение добавлен новый пункт для транскрипции любого аудио- или видеофайла с помощью Whisper. В Параметрах появился новый раздел «AI и транскрипция» с выбором модели, дополнительной поддержкой CUDA (видеокарты NVIDIA), возможностью сохранять исходный язык и включать или отключать временные метки.
• В меню Воспроизведение добавлено новое действие `Транскрибировать текущую папку`, которое транскрибирует все поддерживаемые аудиофайлы из папки открытого медиафайла и объединяет их в один документ, с отдельным окном прогресса, указанием текущего файла и возможностью отмены. Его также можно запустить сочетанием `Alt+Shift+C`.
• Добавлена возможность офлайн-диктовки голосом с тем же принципом работы, что и у транскрипции аудио. По умолчанию нажмите `Ctrl+Shift+Пробел`, чтобы начать диктовку, и нажмите тот же ярлык ещё раз, чтобы завершить её; сочетание клавиш можно настроить в Параметрах. Начиная со второго запуска диктовка работает быстрее, потому что движок остаётся готовым в памяти; на ПК с менее чем 4 ГБ ОЗУ этот предварительный запуск и повторное использование отключаются автоматически.
• В параметрах редактора добавлена новая настройка, отключённая по умолчанию, благодаря которой `Esc` закрывает окно редактора.
• Поиск подкастов теперь по умолчанию использует `iTunes + Spreaker` с фильтрацией дубликатов, когда один и тот же подкаст присутствует на обеих платформах.
• Улучшены поиск и просмотр подкастов Apple: поиск подкастов, просмотр по категориям и списки топ-подкастов по категориям теперь используют выбранную страну каталога подкастов. В Параметры > RSS / Podcast можно оставить `Автоматически`, чтобы использовать системную страну, или вручную выбрать другую страну.
• Sonarpad теперь доступен и на Mac, хотя пока только с частью функций. Ссылка на проект: https://github.com/Ambro86/Sonarpad-Mac

Улучшения
• Добавлено более 50 стран для выбора каталога подкастов, так что теперь доступно значительно больше национальных каталогов.
• Функция «Воспроизведение потокового аудио...» теперь также умеет искать на YouTube по любому текстовому запросу или принимать ссылку на YouTube-канал либо плейлист и показывать их результаты.
• Улучшено отображение результатов в «Воспроизведение потокового аудио...»: элементы YouTube теперь показывают название, длительность, канал и количество просмотров в более понятном формате.
• «Воспроизведение потокового аудио...» теперь также поддерживает комментарии YouTube: их можно открыть из контекстного меню, читать ответы и разворачивать ветки комментариев клавишей Стрелка вправо.
• Добавлены избранные YouTube для каналов и плейлистов в «Воспроизведение потокового аудио...»: их можно добавлять из результатов через контекстное меню, открывать напрямую из списка «Избранное», доступного по Tab сразу после поля URL/поискового запроса YouTube, и позже удалять из этого же списка также через контекстное меню. В результатах поиска YouTube контекстное меню доступно только для каналов и плейлистов.
• Функция «Воспроизведение потокового аудио...» теперь может запрашивать учётные данные, если сайт требует входа. Пользователь может ввести их, сохранить для этого сайта и позже управлять сохранёнными данными в Параметры > Аудио.
• Улучшено управление фокусом во время «Воспроизведение потокового аудио...», чтобы окно прогресса вело себя стабильнее при загрузке и конвертации.
• Добавлены два новых действия чтения в меню Голос: `Предыдущее предложение` и `Следующее предложение`, с настраиваемыми сочетаниями клавиш для перехода во время чтения текста.
• Сочетание клавиш по умолчанию для `Выполнить файл с помощью интерпретатора` теперь `Ctrl+Shift+F5`, чтобы `Shift+F5` можно было использовать по умолчанию для `Предыдущее предложение`.
• В Параметры > Голос добавлены профили голоса: профили можно добавлять, переименовывать и удалять.
• В Параметры > Аудио расширен выбор интервала перемотки назад при воспроизведении: добавлены новые значения от 1 секунды до 2 часов.
• Добавлен русский перевод благодаря Dmitriy.
• В Параметры > Аудио добавлена новая настройка формата имени частей аудиокниги: `Название + номер`, `Только номер` или `Номер + название`.
• Добавлена возможность добавлять статьи RSS в специальную ленту Избранное из контекстного меню статьи.
• Ленту RSS Избранное теперь можно удалить; она будет создана заново автоматически при следующем добавлении статьи в избранное.
• Добавлены сочетания клавиш RSS для перемещения лент вверх и вниз: `Ctrl+Shift+Стрелка вверх` и `Ctrl+Shift+Стрелка вниз`.
• Улучшено окно RSS: добавлен встроенный предпросмотр статьи, чтобы текст можно было читать прямо в окне RSS и быстро переходить к нему клавишей Tab перед открытием полной статьи в редакторе.
• В RSS добавлен явный пункт «Загрузить больше новостей» в конце источника, когда доступны дополнительные элементы; по Enter загружается следующий блок, а фокус переходит на первую новую статью.
• В голосовом словаре при добавлении или редактировании замены теперь доступен флажок «Учитывать регистр», чтобы можно было выбрать, должна ли каждая подстановка учитывать или игнорировать заглавные и строчные буквы.

Исправления
• Исправлен импорт из Википедии: на некоторых страницах цитаты из текста импортировались некорректно.
• Улучшен парсер веб-страниц: на некоторых страницах WordPress не включались элементы списков и некоторые заголовки разделов.
• Теперь при использовании «Перейти к строке» поле заранее заполняется текущей строкой.
• Исправлен экспорт OPML для подкастов и RSS: теперь экспортированные файлы принимаются iTunes.
• Исправлена транскрипция медиафайлов: теперь при закрытии созданного документа через Alt+F4 Sonarpad спрашивает, нужно ли сохранить файл, и предлагает правильное имя на основе имени транскрибированного файла, а не первой строки текста.
• Добавлены локализованные сообщения подтверждения для корректного импорта и экспорта OPML RSS-источников и подкастов.
• «Воспроизведение потокового аудио...» теперь учитывает уже заданный в Параметрах лимит кэша подкастов, и этот же лимит теперь применяется и к воспроизведению аудиоописаний.
• Исправлена проблема, из-за которой в «Воспроизведение потокового аудио...» после ввода поисковой строки и выбора канала YouTube из результатов программа могла выглядеть зависшей вместо открытия видео этого канала.
• Исправлена ошибка, из-за которой список открытых файлов отображался в меню Справка вместо меню Окно.
• Исправлен пограничный случай потокового воспроизведения: воспроизведение могло начаться, но окно «Загрузка потока» оставалось открытым, если загруженный файл уже соответствовал целевому формату.
• Исправлено преобразование потоков MP3: если поток уже является MP3 и пользователь выбирает явный битрейт MP3 (например, 128 кбит/с), Sonarpad теперь перекодирует файл в выбранный битрейт вместо пропуска преобразования.
• Исправлено сочетание клавиш `Alt+Shift+L`: теперь оно корректно открывает список глав во время воспроизведения.
• Исправлено сочетание клавиш `Alt+Shift+T`: теперь оно корректно запускает «Транскрипцию текущего аудио», а не открывает меню Инструменты.
• Если в момент запуска транскрипции уже воспроизводится аудио, Sonarpad теперь автоматически ставит это воспроизведение на паузу перед началом транскрипции.
• Исправлена проблема, из-за которой при импорте статьи из Википедии импорт мог завершиться успешно, но текст статьи не отображался на экране.
• Добавлена поддержка встроенных глав подкастов в локальных медиафайлах (например, метаданных глав MP3): если главы недоступны из feed/URL, Sonarpad теперь загружает их из скачанного файла в фоне, поэтому воспроизведение начинается сразу, а данные глав применяются, как только становятся доступны.
• Исправлена загрузка глав для скачанных эпизодов подкастов, открытых как обычные локальные медиафайлы: встроенные главы теперь доступны и в этом случае, а не только при запуске воспроизведения из окна Подкасты.
• Исправлена финализация MP3-аудиокниг для SAPI4 и SAPI5: итоговый файл теперь корректно завершается, что помогает избежать неполных или нестабильных файлов после длительного экспорта.
• Добавлена явная полоса прогресса для этапа финализации во всех режимах создания аудиокниг: после этапа создания Sonarpad теперь объявляет и показывает отдельную фазу финализации с видимым прогрессом.
• Исправлена настройка голосов диалога: параметры скорости, высоты тона и громкости теперь корректно применяются как к первому, так и ко второму голосу диалога во время синтеза.
• Улучшено определение кодировки японских файлов `.txt`: добавлен безопасный резервный вариант Shift_JIS/CP932 для случаев mojibake, при сохранении существующего поведения для UTF, диакритики и китайского текста.
• Внутренний рефакторинг безопасности: где возможно, функции переведены на safe-реализации, а количество строк unsafe-кода заметно сокращено.
