使用指南

文件：
新建：创建新文档（Ctrl+N）。
打开：打开文本文件、PDF、EPUB、MP3及其他支持的格式（Ctrl+O）。
保存：保存文档（Ctrl+S）。
另存为：以新名称保存。
全部保存：保存所有文档（Ctrl+Shift+S）。
最近使用的文件：打开最近使用的文件。

多媒体文件：
当您打开多媒体文件（MP3、WAV、MP4、AVI）时，Sonarpad 会变成一个音频播放器。
键盘控制：
- SPACE：播放/暂停。
- 右箭头：快进1分钟。
- 左箭头：倒退1分钟。
- 上箭头键：调高音量。
- 下箭头：降低音量。
- +：加快播放速度。
- -：降低播放速度。
- SHIFT +: 提高音高。
- SHIFT -: 降低音高。
- CTRL+I：播报当前播放时间。
- CTRL+T：跳转至特定时间点。
- CTRL+B：在精确时间处插入书签。

编辑：
撤销：撤销上一步操作（Ctrl+Z）。
剪切：删除选定文本并将其复制到剪贴板（Ctrl+X）。
复制：将选定文本复制到剪贴板（Ctrl+C）。
粘贴：将剪贴板内容粘贴到文档中（Ctrl+V）。
全选：选中所有文本（Ctrl+A）。
查找：在文档中搜索文本（Ctrl+F）。
在多个文件中查找：在多个文件中搜索文本（Ctrl+Shift+F）。
查找下一个：查找下一个出现位置（F3）。
替换：查找并替换文本（Ctrl+H）。
规范化空格：删除行首和行尾空格，并压缩连续空格（Ctrl+Shift+Enter）。
合并行：将段落或选定内容中的多行合并为一行（Ctrl+Shift+J）。
重新排版：重新调整段落或选定文本的换行格式（Ctrl+Shift+H）。
移除 Markdown 标签：删除 Markdown 标签（Ctrl+Shift+M）。
排序项目：对段落或选定行进行排序（Alt+Shift+O）。
保留唯一项目：删除段落或选定内容中的重复行（Alt+Shift+K）。
反向项目：反转段落或选定内容中的行（Alt+Shift+Z）。
添加引用前缀：为段落或选定文本中的每行添加前缀（Ctrl+Q）。
移除引用前缀：删除段落或选定文本中每行的前缀（Ctrl+Shift+Q）。
文本统计：显示所选内容或文档的字符、单词和行数（Alt+Y）。
拼写检查导航：F7 上一个错误，F8 下一个错误。

查看：
在编辑器中显示语音：显示语音系统、语音列表及多语言过滤器。
显示收藏语音：在编辑器中显示收藏语音列表。
文本颜色：更改文本颜色（浅色/深色主题）。
文字大小：更改文字大小（小、正常、大、特大、超大）。
当条目列表可见时，按Tab键可在编辑器和控件之间移动焦点，而Shift+Tab键则向后移动焦点。
要将条目添加至收藏夹或从收藏夹移除，请使用Tab键移动至条目列表，然后通过应用程序键或鼠标右键进行添加或移除操作。在收藏夹条目列表中，您也可按下应用程序键移除已添加的条目。
键盘快捷键：阅读时可按F9和F10在条目间切换，循环浏览已添加至收藏夹的条目。

书签：
插入书签：保存当前光标位置或有声书时间（Ctrl+B）。
管理书签：查看、跳转或删除已保存的书签。打开包含书签的文件时，光标或播放会从第一个可用书签位置继续。

语音与音频：
阅读：F5 开始阅读，F4 暂停/继续，F6 停止阅读。
上一句：Shift+F5 在阅读时跳到上一句。
下一句：Ctrl+F5 在阅读时跳到下一句。
阅读时收藏语音切换：F9 上一个收藏语音，F10 下一个收藏语音。
录制有声书：将当前文本生成 MP3 文件（Ctrl+R）。
批量有声书：将文件列表转换为有声书（Ctrl+Shift+B）。
录制播客：通过麦克风和/或系统音频录制播客（Ctrl+Shift+R）。
音频转换：将音频/视频文件转换为其他音频格式（Ctrl+Shift+A）。
使用解释器执行文件：用已配置的解释器运行当前文件（Ctrl+Shift+F5）。

工具：
批量有声书：打开一个窗口，将文件列表（或整个文件夹）转换为有声书。
- 将文件/文件夹添加到队列中。
- 选择目标文件夹和格式（MP3 或 WAV）。
- 创建子文件夹并避免覆盖的选项。
- 按下开始键，在后台处理所有内容。
词典：打开词典窗口。通过上/下箭头键浏览词条列表。
Tab键移动至"将条目添加至词典"按钮，按Enter键或空格键即可激活。
在添加/编辑窗口中：输入"原始词语"，然后按Tab键切换至"替换词语"，接着点击确定或取消（Enter/空格键）。ESC键取消操作。
在列表中，Tab键可移动至"编辑条目"和"删除所选条目"。
词典替换在阅读和有声书制作过程中应用，并被保存。
导入YouTube字幕：粘贴URL，选择语言，将文本导入编辑器（Ctrl+Y）。可选时间戳。
从维基百科搜索并导入：在维基百科上搜索文章，将其文本导入编辑器（Alt+Shift+W）。
在线词典：在在线维基词典中搜索词义和翻译（Alt+Shift+D）。
播放流媒体音频（Alt+Shift+S）：从 YouTube 等流媒体网站播放音频，可选择格式和质量，并可在不下载的情况下收听（例如用于在线广播）。
无障碍终端：打开专用的终端窗口，为屏幕阅读器提供稳定的输出（Ctrl+Shift+T）。
快捷键：Alt+I 聚焦输入框，Alt+O 聚焦输出框，Tab/Shift+Tab 在输入框、输出框和选项之间切换。
按下回车键发送输入。Ctrl+C复制输出内容（或向程序发送Ctrl+C）。Ctrl+L清除输出内容并进行确认。
终端选项：自动滚动，清除ANSI字符，提示新行，闲置1秒后蜂鸣，禁止休眠。
终端类型：命令提示符（cmd.exe）、PowerShell、Codex CLI（可在选项中选择）。

RSS / 文章：打开RSS/文章窗口，添加来源，展开订阅源，按Enter键将文章导入编辑器。
在RSS窗口中，选中一个订阅源或站点，按下删除键即可将其从库中移除。
在订阅源或网站的上下文菜单中，您可以编辑或删除RSS源或网站。
导入RSS文章后，按Esc键返回RSS列表。
播客：打开播客窗口以搜索和管理订阅。
在剧集列表中，按下回车键即可播放该剧集。
播放时按Esc键可停止播客并返回媒体库。

选项
“选项”窗口允许您自定义 Sonarpad 的行为。设置分为不同的选项卡。
常规
界面语言：允许选择程序的语言。
文件打开方式（新标签页 / 新窗口）：选择“新标签页”时，可使用 Ctrl+Tab 在已打开的文件之间切换。选择“新窗口”时，可使用 Alt+Tab 在窗口之间切换。
启动时检查更新：在程序启动时自动检查更新。
发送匿名崩溃报告：自动向程序作者发送匿名错误报告。
添加到右键菜单“使用 Sonarpad 打开”：在文件资源管理器中添加选项，可直接使用 Sonarpad 打开文件。
文件关联：打开 Windows 窗口，用于管理 Sonarpad 支持的文件关联。
全局代理：允许配置代理服务器，用于程序的所有网络连接。
语音
TTS 引擎（Microsoft / SAPI5 / SAPI4）：允许选择用于朗读的语音引擎。
主语音：选择用于朗读文本的语音。对于 Edge 语音，提供按语言筛选的附加字段，以及“仅多语言语音”选项。
语音预览：播放所选语音的示例。
音高、语速和音量：允许调整这些参数。
对话使用不同语音：启用后，可为对话部分使用不同的语音。
第一对话语音（可选）：为对话设置一个特定语音。
第二对话语音（可选）：为对话添加第二个语音。
启用后，Sonarpad 最多可使用三种不同的语音。
编辑器
自动换行：启用或禁用自动换行。
行宽：设置每行的最大字符数。
智能引号：自动将直引号替换为排版引号。
拼写检查：启用当前语言的拼写检查。
词典翻译语言：设置在线词典的目标语言。
维基百科语言：选择用于维基百科搜索的语言。
音频
前进/后退跳转间隔：设置播放时跳转的秒数。
默认有声书文件夹：设置生成的有声书保存位置。
有声书分割：不分割、按文本分割、按指定部分数量分割或按时长分割。
字幕选项：允许选择在播放媒体文件时如何处理字幕。
RSS 和 播客
播客缓存限制：设置下载播客所使用的最大空间。
Podcast Index（API key / API secret）：输入 Podcast Index 的凭据。
确认删除 RSS/播客：删除项目之前显示确认消息。
未读/未播放状态提示：显示项目是否已阅读或播放。
日期/时间显示：允许自定义日期和时间的显示方式。
RSS 快速复制：允许选择按 Ctrl+C 时复制的内容。
快捷键
带有可编辑快捷键的命令列表。
记录新的按键组合。
恢复默认快捷键。
窗口：打开窗口菜单。
已打开的文档...：显示已打开文档的列表。
关闭其他：关闭除当前活动文档之外的所有文档。
全部关闭：关闭所有已打开的文档。

帮助：
指南：打开本指南（F1）。
检查更新：检查是否有可用更新（F2）。
变更日志：打开变更日志窗口。
关于：显示程序信息。
